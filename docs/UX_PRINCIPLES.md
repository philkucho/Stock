# UX 원칙 설계서

본 문서는 미국주식 단타 자동매매 시스템의 모든 사용자 직면 UI(Next.js 페이지, 알림, 에러 메시지, CLI 안내문)에 적용되는 설계 원칙을 정의한다. 새 페이지/컴포넌트를 만들거나 기존 화면을 수정할 때 반드시 본 문서를 참조한다.

---

## 1. 목적과 대상 사용자

### 목적
- 자동매매 시스템의 의사결정(왜 이 종목을, 왜 이 가격에)을 사용자가 **즉각 이해**할 수 있게 한다.
- 단타 시스템 특성상 빠른 판단이 필요하므로, 정보 해독에 시간을 쓰지 않게 한다.
- 영문 전문 약어로 인한 학습 비용을 최소화한다.

### 대상 사용자
- **트레이딩 경험 있는 한국어 사용자**
- 기본 시장 용어(매수/매도, 손절, 차트, 갭 등)는 안다고 가정
- 시스템 고유 용어(RVOL, Gate 6, S1~S5 등)는 **모른다고** 가정 → 한글 라벨 또는 툴팁 필수
- 개발자 본인도 포함되지만, 본인 이외 사용자가 봐도 이해 가능한 수준이 기준선

### 적용 범위
- `frontend/app/**/*.tsx` 의 모든 사용자 직면 페이지
- API 에러 메시지 (FastAPI → 사용자에게 전달되는 문자열)
- 알림(차후 추가될 푸시/이메일 등)
- 비적용: 내부 로그, 디버그 출력, Jupyter 노트북 (개발자 전용)

## 2. 핵심 원칙

### P1. 한글 우선
영어 약어 단독 표기 금지. 다음 중 하나의 형식 사용:
- **병기**: `상대거래량(RVOL)`
- **한글 라벨 + 툴팁**: 라벨은 `상대거래량`, hover 시 툴팁 `RVOL = Relative Volume`
- **종목 코드 등 고유명사**는 영문 유지 (예: AAPL, SPY) — 이런 경우 툴팁으로 풀이 (예: SPY = S&P 500 ETF)

### P2. 의사결정 근거를 보여줘라
점수만 노출 금지. **"왜 이 종목인지" 한 줄 요약**을 점수와 함께 표시한다.
- 좋은 예: `📰 재료: 실적 발표 (출처: yfinance)` + `갭 +3.2%, 거래량 5배 폭증`
- 나쁜 예: `Total Score: 18.5` 만 표시

### P3. CLI 명령어를 사용자 화면에 노출 금지
- 액션은 모두 **버튼**으로 추상화한다 (예: `↻ 종목 다시 선정`).
- 예외 1: 백엔드/서비스가 죽었을 때 fallback 안내. 이 경우 `<details>` 안에 `관리자용` 라벨로 접어둔다.
- 예외 2: 명시적인 "관리자/개발자 모드" 토글 (현재 미구현).

### P4. 위험 관련 정보는 시각적으로 강조
- **손절가, 위험비율(Risk%)**: 빨간색 + 텍스트 라벨 `손절`/`위험` 동시 노출 (색맹 대비).
- **목표가**: 녹색.
- **모의투자 단계 표시**: 페이지 하단 또는 상단 배너에 항상 노출 (`현재 모의투자(paper) 단계`).

### P5. 진행 중/대기/오류 상태를 명시
- `Loading…` 같은 영어/모호한 표현 금지.
- 형식: `<무엇을> <상태>` (필요시 예상 시간 추가)
  - 좋은 예: `오늘 종목 불러오는 중`, `종목 다시 선정 중 (예상 30초)`, `API 서버 응답 없음`
  - 나쁜 예: `Loading…`, `Error`, `Failed`

## 3. 용어집 (Glossary)

시스템에서 사용되는 모든 영어 약어와 한글 라벨 매핑. 신규 약어 추가 시 본 표에 등재 후 사용한다.

### 종목 선정 (Daily Picks)
| 영어 | 한글 라벨 | 설명 |
|---|---|---|
| RVOL | 상대거래량 | 평균 대비 오늘 거래량 배수 (5배면 RVOL = 5) |
| Pivot | 진입가 | 매수 진입 기준 가격 |
| Stop | 손절가 | 손실 제한을 위한 매도 기준 가격 |
| 1R | 1차 목표가 | 위험 1배만큼의 수익 가격 (Pivot + Risk) |
| 2R | 2차 목표가 | 위험 2배만큼의 수익 가격 (Pivot + 2×Risk) |
| Risk per share | 주당 위험 | Pivot − Stop |
| Position Size | 주식수 | 자본 대비 위험 비율로 계산된 매수 주식 수 |
| Gate 6 | 6단계 1차 필터 | 시장/거래대금/모멘텀/스프레드/재료/함정 필터 6개 |
| Score 24 | 24점 만점 점수 | 5개 요소(S1~S5) 가중 합계 |
| S1 Gap+RVOL | 갭+거래량 점수 | 개장 갭과 거래량 폭증 정도 (최대 7점) |
| S2 Catalyst | 재료 점수 | 실적/뉴스/FDA 등 카탈리스트 (최대 4점) |
| S3 Setup | 차트 패턴 점수 | tight_flag, 52w 근접 등 셋업 (최대 8점) |
| S4 Sector | 섹터 강도 점수 | 동일 섹터 동조성 (최대 3점) |
| S5 Whitelist | 검증 종목 점수 | 과거 성과 검증된 종목 가산점 (최대 2점) |
| catalyst_summary | 재료 요약 | 종목 선정 사유 한 줄 요약 |
| strategy_tag = swing | 스윙 | 며칠~몇주 보유 전략 |
| strategy_tag = day | 단타 | 당일 청산 전략 |

### 시장 컨텍스트
| 영어 | 한글 라벨 | 설명 |
|---|---|---|
| Market Context | 시장 분위기 | 주요 지수의 개장 갭 정보 |
| SPY | S&P 500 | 미국 대형주 500개 평균 ETF |
| QQQ | 나스닥 100 | 미국 기술주 위주 100개 평균 ETF |
| IWM | 러셀 2000 | 미국 중소형주 2000개 평균 ETF |

### 백테스트/매트릭스 (참고 — 별도 phase에서 한글화 예정)
| 영어 | 한글 라벨 | 설명 |
|---|---|---|
| ROBUST | 신뢰 | 견고하게 검증된 전략 (이미 frontend 적용 — 패턴 유지) |
| OVERFIT | 과적합 | 학습 데이터에 과도 최적화 의심 |
| DECAYED | 노후 | 최근 성과 저하 |
| Fitness | 적합도 | 전략-종목 적합도 점수 |
| Sharpe | 샤프 비율 | 위험 대비 수익률 (높을수록 좋음) |
| MDD | 최대낙폭 | Maximum Drawdown — 최대 손실 구간 (낮을수록 좋음) |

## 4. 컴포넌트 패턴

### PickCard (종목 카드) 표준 구조
```
[순위] [종목명]  [전략 배지: 스윙/단타]                  [총점] [등급 A/B/C]
[섹터]
📰 재료: [한 줄 요약 + 출처]

진입가  $123.45      손절가  $120.00 (빨강)
1차 목표 $126.90      2차 목표 $130.35
주식수   100주       위험비율 2.8%

▸ 점수 상세 보기  (접힘, 펼치면 갭+거래량/재료/차트패턴/섹터/검증종목 점수 표시)
```

핵심 규칙:
- **기본 노출**: 종목, 카탈리스트, 가격 정보, 총점.
- **접어둠**: Score breakdown(상세 점수) — 일반 사용자에겐 노이즈, 개발자/검증용.
- **위험 컬러**: 손절가/위험비율은 빨간색.
- **목표가 컬러**: 1차/2차 목표는 녹색.

### 에러/빈 상태 (EmptyState)
1. **무엇이 비어있는지** 한 줄 설명
2. **다음에 할 액션** 버튼 (1~2개)
3. **CLI fallback**은 `<details>` `관리자용`으로 접어둠

좋은 예:
```
오늘의 종목이 아직 선정되지 않았습니다.
[↻ 지금 종목 선정하기]  [도움말]

▸ 관리자용 (CLI 명령어)
```

### 숫자 포맷 표준
- **가격**: `$123.45` (소수점 2자리, $ 접두)
- **비율**: `+12.3%` (부호 포함, 소수점 1자리)
- **거래대금**: `$1.2M` 또는 `$120만` (한글 단위 가능)
- **주식수**: `100주` (한글 단위)
- **점수**: `18.5` (소수점 1자리)

### 상태 메시지 패턴
| 상태 | 메시지 형식 |
|---|---|
| 로딩 | `[대상] 불러오는 중` |
| 처리 중 | `[작업명] 중 (예상 [시간])` |
| 성공 | `✓ [완료한 것]` |
| 실패 | `✗ [실패한 것] — [원인 한 줄]` |
| 빈 상태 | `[무엇이] 없습니다. [다음 액션 제안]` |
